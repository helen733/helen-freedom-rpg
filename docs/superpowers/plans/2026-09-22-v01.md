# 海伦自由人生 RPG V0.1

目标：用手机可用的单页静态 PWA，完成 7 天赚钱挑战。无需登录、后端或外部服务。

设计：奶油纸色、深咖啡棕、森林绿、铜色；角色档案与每日任务并列，手机纵向排列。无动画、无聊天。保留用户提供的角色、属性、Boss 与奖励文案。

执行顺序：
- [x] 用 Node 内置测试验证经验、撤销、7 天解锁、本地存档数据校验。
- [x] 实现独立状态模块与 HTML/CSS/JS 首页。每项任务 20 XP，每 100 XP 升级；撤销同步回退，不能反复刷分。非空任务才可完成。
- [x] 每天 3 项任务全部完成才可手动开启下一天；不强制日历日期，不因缺席惩罚用户；可回看、修改过去任务。
- [x] 完成 21 项任务可领取一次青铜宝箱；500 元为用户自行安排的奖励预算，不是实际发钱。
- [x] 添加 manifest、本地图标和离线缓存；应用数据 localStorage 保存，异常明确提示；存档导出与恢复为最低限度数据保护。
- [x] 验证核心逻辑、浏览器交互、窄屏布局和离线加载，提供本地启动及手机访问说明。

文件边界：dist/state.js 负责纯状态规则；dist/app.js 负责存储及界面；dist/styles.css 负责响应布局；dist/sw.js 负责缓存；server.mjs 仅提供开发预览，不是应用后端。
