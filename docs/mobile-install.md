# 海伦自由人生 RPG · 手机安装与长期使用

正式入口：<https://helen-freedom-rpg.helen733.chatgpt.site/>

## 第一次安装

1. 用手机 Safari（iPhone）或 Chrome（安卓）直接打开正式入口，不在微信文件预览里打开。
2. 等页面底部出现“离线已就绪 · 数据保存在本机”。这表示离线文件已安装完成。
3. iPhone：分享 → 添加到主屏幕 → 添加；若系统显示“作为网页 App 打开”，保持开启。
4. 安卓：浏览器菜单 → 安装应用 / 添加到主屏幕；也可点页面顶部“添加到桌面”。
5. 从手机桌面点击“海伦自由人生”图标打开。可临时开启飞行模式再打开一次，确认这台手机的离线入口正常。

首次下载应用和接收更新需要网络；下载完成后，打开角色面板、编辑任务、完成任务、查看经验与宝箱、保存进度均在本机完成。电脑可关机，`启动应用.cmd` 不需要运行，手机不需要与电脑连接同一网络。

实际安装菜单因手机系统和浏览器版本而异。如果看不到安装项，请在系统 Safari / Chrome 中打开，确认地址为 HTTPS，而不是微信内置浏览器或旧局域网地址。

## 从旧版本迁移进度

新正式网址与旧局域网网址属于不同的网站存储空间，不能直接读取旧存档。为保护数据，不做隐藏搬迁或清空操作。

1. 在原来保存进度的浏览器中打开旧入口，点击页面底部“导出存档”，把 JSON 保存到手机“文件”或下载目录。旧入口只需在这一步暂时运行。
2. 打开正式入口或安装后的桌面应用，点“恢复存档”，选择该 JSON 并确认。
3. 检查任务和经验是否正确。以后每天使用正式桌面图标。

如果 iPhone 的网页与桌面应用使用不同的存储空间，直接在桌面应用内恢复同一份 JSON。不要删除旧存档或备份，直到确认新入口的进度正确。

## 数据与更新

- 任务、经验和奖励记录只保存在当前设备当前入口的本地存储中，不上传到服务器。
- 更新应用文件不会改动 `helen-freedom-rpg-v1` 存档。
- 已缓存的界面优先立即打开；联网时在后台获取更新，之后再次打开即可使用更新内容。
- 手机清理网站数据、隐私浏览、卸载或更换设备可能影响本地数据。定期“导出存档”即可保留可恢复的副本。
- “离线尚未就绪”时保持联网，再次打开。不要在这个状态下把离线启动当成已经安装成功。

## 后续开发

继续维护现有 `dist/styles.css`、`dist/app.js`、`dist/state.js`，运行 `npm run build` 后发布同一站点。未来可以在这个入口内逐步增加内容，不必让用户反复安装其他 App。此次没有新增地图、聊天或游戏系统。

`.openai/hosting.json` 记录同一个托管项目与静态目录。不要随意更换域名、manifest 的 `id` 或存档键；如需变更，先提供迁移方案。
