# ☕ 海伦自由人生 RPG · V0.1

一个温暖、轻量的个人成长与赚钱挑战游戏首页。纯 HTML / CSS / JavaScript，无框架、无登录、无数据库、无应用后端；数据只保存在当前浏览器。

GitHub Pages 自动部署配置已准备好，尚未在 GitHub 发布。按 [最短配置步骤](docs/github-pages.md) 上传项目，在 Settings → Pages 选择 GitHub Actions，再运行 Deploy GitHub Pages 工作流即可。源码上传包为项目根目录的 `github-pages-upload.zip`，请先解压再上传。

## 电脑开发预览（仅维护时使用）

安装 Node.js 后，在项目目录运行：

```powershell
npm start
```

打开 http://localhost:4173 。也可以双击项目中的 `启动应用.cmd`。预览期间保持命令窗口运行。

新版 `dist/index.html` 已内嵌完整样式和脚本。在支持 JavaScript 的正常浏览器里，即使只保留这一个文件，也能显示原有 UI 并运行任务交互。微信、文件管理器的预览窗口可能禁止脚本和存储，不能替代日常使用的浏览器。`file://` 本地文件也不能启用 PWA；推荐通过上面的网页地址打开。这里的启动程序只提供静态文件，不存储任何应用数据。

## 移动端加载修复

旧版 HTML 的 `./styles.css` 与 `./app.js` 路径并没有拼错。问题发生在将 HTML 单独传给手机或使用受限制的文件预览器时：预览器不能读取相邻文件，导致 CSS 丢失；`file://` 下的模块脚本还可能被浏览器的跨源限制阻止。

当前版本把原有 CSS 和 JS 打包到 `index.html` 中，不再依赖外部 CSS / JS 请求来展示和启动页面。`styles.css`、`app.js`、`state.js` 仍保留为可维护源码，设计和游戏规则没有改变。入口中的 manifest、favicon、Apple 图标仍使用同目录相对路径。

顶部加载诊断独立于主程序和主样式：CSS 未生效、JS 未启动、运行错误、PWA 注册失败时会显示原因；脚本被彻底禁止时，静态提示仍可见。本地文件模式会提示使用限制。正常网页打开时这些提示自动隐藏，不改变原界面。

完整排查证据、修改清单与项目结构见 [移动端加载修复说明](docs/mobile-loading-fix.md)。

## 游戏规则

- 初始角色：规则破解者，Lv.1 新手破解者。
- 现金流 20/100、自由度 30/100、破解能力 90/100；执行力当前恢复中。V0.1 属性为角色设定，不会把 XP 当成真实收入。
- 每天 3 项自定义任务，每项最多 160 字，输入后自动保存；空任务不能完成。
- 每项完成获得 20 XP，每 100 XP 升 1 级；重复勾选不能刷分，撤销完成会回退相应经验与等级。
- 完成当天全部任务后，手动点击“开启 Day N”。每天按行动进度推进，不锁定日历日期，不因中断清零。
- 可以回看并修改已解锁的天数；修改文字为全空会撤销该任务完成状态。
- 7 天全部 21 项任务完成后，开启青铜宝箱。500 元是用户自行安排的自由奖励基金，不是应用发钱。
- 宝箱领取只记录一次，领取后的成就记录保留；若撤销旧任务，任务进度与 XP 仍会回退。
- Day 2–7 暂沿用“无限优化怪”和“先验证，再优化”的主题，不引入额外内容系统。

## 存档

数据保存在 `localStorage`，键为 `helen-freedom-rpg-v1`。无网络同步；更换设备、浏览器、网址或清理网站数据不会自动带走存档。隐私模式和浏览器清理可能删除数据，请定期使用页脚“导出存档”。

“恢复存档”会验证 JSON 格式，确认后替换当前数据。可通过导出与恢复在设备间迁移。正式更换访问网址前，先导出存档。不同手机系统可能把桌面应用与普通网页的存储分开，也可通过该方式迁移。

若检测到损坏存档，应用保留原始数据并提示，不自动覆盖。若浏览器禁止存储或空间不足，会显示保存失败提示。

同时打开多个窗口时，会同步当前浏览器的存档变化；保存前也会检查旧窗口是否落后。如果检测到冲突，先加载最新进度并提示重新操作，避免直接用旧进度覆盖。

## 文件与验证

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` / `styles.css` | 自包含首页 / 原始样式源码 |
| `dist/state.js` | 挑战、经验、数据校验规则 |
| `dist/app.js` | 界面交互、存档与安装 |
| `dist/load-check.js` | 独立加载诊断，构建时内嵌 |
| `dist/sw.js` | 离线缓存 |
| `dist/manifest.webmanifest` / `icons/` | PWA 配置与图标 |
| `server.mjs` | 零依赖本地静态预览 |
| `scripts/build.mjs` | 零依赖打包，生成完整 HTML |
| `tests/state.test.mjs` | 核心规则测试 |
| `tests/browser.mjs` | 浏览器端完整流程验证 |
| `tests/loading.browser.mjs` | 文件打开、资源失败、子目录与离线回归测试 |

修改页面正文可编辑 `dist/index.html` 中非自动生成的区域；修改样式和逻辑应编辑对应 `.css` / `.js` 源文件，然后运行：

```powershell
npm run build
npm run check
```

不要直接修改 HTML 中 `BEGIN:INLINE_STYLES`、`BEGIN:LOAD_CHECK`、`BEGIN:APP_BUNDLE` 到对应 `END` 之间的生成内容。打包程序会检查源码语法，并在不支持的模块结构变化时明确报错。`npm start` 与一键启动都会在启动前自动打包。

```powershell
npm test
```

浏览器测试需要 Playwright 和 Microsoft Edge：安装 Playwright 或设置 `PLAYWRIGHT_PATH` 为现有 Playwright 包路径，再运行 `node tests/browser.mjs` 及 `npm run test:loading`。运行前保持 `npm start` 开启。测试用全新浏览器上下文，不影响实际用户存档。

已验证：320 / 390 / 768 / 1440 像素宽度无横向溢出；任务编辑与撤销；刷新恢复；完整 7 天与升级；宝箱只领取一次；有效存档导出与恢复、无效存档拒绝；Service Worker 离线刷新；无 JavaScript 运行错误。尚未在实体 iPhone / 安卓手机验证系统安装流程。

升级静态资源时修改 `sw.js` 中的缓存版本名称，让新缓存替换旧资源。不要改动存档键或结构，除非同时提供数据迁移。
